# den-api Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a single Hertz process that implements the confirmed den v1 POST API, server-authoritative dice, Redis matchmaking, and room WebSocket fanout, with `go test ./...` passing.

**Architecture:** One Go module at `/opt/game/server`. PostgreSQL stores users, rooms, matches, and dice. Redis stores tokens, presence, and match queues. Hertz serves `/den/v1/{service}/{Action}`. WebSocket upgrade on `/den/v1/room/Subscribe` fans out the same JSON envelope. Dice values are generated only on the server.

**Tech Stack:** Go 1.26, github.com/cloudwego/hertz v0.10.6, github.com/jackc/pgx/v5 v5.13.0, github.com/redis/go-redis/v9 v9.23.0, github.com/google/uuid v1.6.0, github.com/hertz-contrib/websocket v0.2.0, github.com/gorilla/websocket v1.5.3 (test client only), github.com/testcontainers/testcontainers-go v0.45.0 and its postgres and redis modules, postgres:16-alpine, redis:7-alpine.

## Global Constraints

- Product module is `den`. Business path is `/den/v1/{service}/{Action}`. Services are only `account`, `hall`, `room`, `match`, and `dice`.
- Business commands are POST. The WebSocket handshake is GET because RFC 6455 requires it. Its URL is `/den/v1/room/Subscribe`. The first frame is `{"Token":"<token>","RoomId":"<room-id>"}`.
- Handled failures are HTTP 200 with `ResponseMetadata` and `Error`, and no `Result`. Unhandled panics are HTTP 500, `Code` `100001`, `Message` `System Error`, and empty `Detail`.
- `RequestId` is a server-generated UUID. Logs include `RequestId`, `Action`, `Version`, and `Service`. `Version` is `v1`.
- HTTP auth header is `Authorization: Bearer <token>`. `GuestLogin` has no token. Tokens last 7 days and rotate on the next login.
- Nicknames may duplicate. Length is 2 to 12 Unicode code points. An empty guest nickname becomes `玩家` plus four digits.
- `MaxSeats` is 2 to 6 and defaults to 4. `Mode` is `HighRoll` or `LiarsDice`. Room codes are 6 digits. Room status is `Open`, `Playing`, or `Closed`.
- The server accepts `LiarsDice`. This plan does not build the Cocos client.
- Dice are 5 integers from 1 to 6, created by the server. A second `Roll` in the same round and seat returns `300002` and does not change the dice.
- High roll compares the sum, then the dice sorted descending. A shared best hand is `Outcome` `Draw` and `WinnerSeat` `-1`. Otherwise `Outcome` is `Win`.
- Liar's dice: 1 is not wild. Calls strictly increase by count, or by face when the count is equal. The lowest occupied seat acts first, then seats ascend and wrap. Only that seat may `Call` or `Open`. `Open` is illegal before the first call. If the actual count of that face is greater than or equal to the call, the caller wins. One round, no hit points.
- Match only players with the same `Mode` and the same `MaxSeats`. `StartMatch` returns immediately with `Status` `Waiting`. `DescribeMatch` reveals `Matched`. A `Waiting` match stays `Waiting` until it matches or is canceled. There is no 30-second server timeout.
- Error codes and messages: `100001` System Error, `100002` Invalid Parameter, `100003` Unauthorized, `200001` Room Not Found, `200002` Room Full, `200003` Not In Room, `200004` Not Host, `200005` Not Ready, `300001` Not Your Turn, `300002` Illegal Action, `400001` Match Not Found, `400002` Match Closed, `400003` Already Matching.
- Redis keys: `den:token:{token}`, `den:user-token:{user_id}` (rotation pointer required by token rotation), `den:online:{user_id}` with a 60-second TTL, `den:room:{room_id}`, `den:match:queue:{mode}:{max_seats}`, `den:match:user:{user_id}`.
- Do not read, modify, or commit `/opt/game/.env`. Do not change git config. Do not copy 猛兽派对 names, art, or text into this service.
- Cocos is a later plan. This plan ends when `go test ./...` passes and `docker compose up -d` plus the server process serves `GuestLogin`.

package envelope

import (
	"context"
	"log"

	"github.com/cloudwego/hertz/pkg/app"
	"github.com/cloudwego/hertz/pkg/protocol/consts"
	"github.com/google/uuid"
)

type Metadata struct {
	RequestId string `json:"RequestId"`
	Action    string `json:"Action"`
	Version   string `json:"Version"`
	Service   string `json:"Service"`
}

type errorBody struct {
	Code    string `json:"Code"`
	Message string `json:"Message"`
	Detail  string `json:"Detail,omitempty"`
}

type success struct {
	ResponseMetadata Metadata `json:"ResponseMetadata"`
	Result           any      `json:"Result"`
}

type failure struct {
	ResponseMetadata Metadata  `json:"ResponseMetadata"`
	Error            errorBody `json:"Error"`
}

func meta(service, action string) Metadata {
	m := Metadata{RequestId: uuid.NewString(), Action: action, Version: "v1", Service: service}
	log.Printf("RequestId=%s Action=%s Version=%s Service=%s", m.RequestId, m.Action, m.Version, m.Service)
	return m
}

func OK(c *app.RequestContext, service, action string, result any) {
	c.JSON(consts.StatusOK, success{ResponseMetadata: meta(service, action), Result: result})
}

func Fail(c *app.RequestContext, status int, service, action, code, message, detail string) {
	c.JSON(status, failure{
		ResponseMetadata: meta(service, action),
		Error:            errorBody{Code: code, Message: message, Detail: detail},
	})
}

func Recovery() app.HandlerFunc {
	return func(ctx context.Context, c *app.RequestContext) {
		defer func() {
			if rec := recover(); rec != nil {
				log.Printf("panic=%v", rec)
				Fail(c, consts.StatusInternalServerError, "den", "Unknown", "100001", "System Error", "")
			}
		}()
		c.Next(ctx)
	}
}
```

import (
	"context"
	"sync"
	"testing"
	"time"

	"den/internal/platform/schema"

	"github.com/jackc/pgx/v5/pgxpool"
	"github.com/redis/go-redis/v9"

	tcredis "github.com/testcontainers/testcontainers-go/modules/redis"
)

var (
	once sync.Once
	pool *pgxpool.Pool
	rdb  *redis.Client
	booted error
)

func Start(t *testing.T) (*pgxpool.Pool, *redis.Client) {
	t.Helper()
	once.Do(func() {
		ctx, cancel := context.WithTimeout(context.Background(), 2*time.Minute)
		defer cancel()
		pg, err := tcpostgres.Run(ctx, "postgres:16-alpine",
			tcpostgres.WithDatabase("den"),
			tcpostgres.WithUsername("den"),
			tcpostgres.WithPassword("den"),
			tcpostgres.BasicWaitStrategies(),
		)
		if err != nil {
			booted = err
			return
		}
		dsn, err := pg.ConnectionString(ctx, "sslmode=disable")
		if err != nil {
			booted = err
			return
		}
		pool, err = pgxpool.New(ctx, dsn)
		if err != nil {
			booted = err
			return
		}
		if _, err = pool.Exec(ctx, schema.SQL); err != nil {
			booted = err
			return
		}
		rc, err := tcredis.Run(ctx, "redis:7-alpine")
		if err != nil {
			booted = err
			return
		}
		url, err := rc.ConnectionString(ctx)
		if err != nil {
			booted = err
			return
		}
		opt, err := redis.ParseURL(url)
		if err != nil {
			booted = err
			return
		}
		rdb = redis.NewClient(opt)
	})
	if booted != nil {
		t.Fatal(booted)
	}
	ctx := context.Background()
	if _, err := pool.Exec(ctx, `TRUNCATE dice_calls, dice_hands, dice_rounds, matches, room_seats, rooms, users`); err != nil {
		t.Fatal(err)
	}
	if err := rdb.FlushDB(ctx).Err(); err != nil {
		t.Fatal(err)
	}
	return pool, rdb
}
```

package account

import (
	"context"
	"crypto/rand"
	"encoding/hex"
	"encoding/json"
	"fmt"
	"time"
	"unicode/utf8"

	"den/internal/envelope"

	"github.com/cloudwego/hertz/pkg/app"
	"github.com/google/uuid"
	"github.com/jackc/pgx/v5"
	"github.com/jackc/pgx/v5/pgxpool"
	"github.com/redis/go-redis/v9"
)

type Handler struct {
	Pool  *pgxpool.Pool
	Redis *redis.Client
}

type guestReq struct {
	DeviceId string `json:"DeviceId"`
	Nickname string `json:"Nickname"`
}

func (h *Handler) GuestLogin(ctx context.Context, c *app.RequestContext) {
	var req guestReq
	if err := json.Unmarshal(c.Body(), &req); err != nil {
		envelope.Fail(c, 200, "account", "GuestLogin", "100002", "Invalid Parameter", "body must be JSON")
		return
	}

func Authenticate(rdb *redis.Client, service, action string) app.HandlerFunc {
	return func(ctx context.Context, c *app.RequestContext) {
		header := string(c.GetHeader("Authorization"))
		token := strings.TrimPrefix(header, "Bearer ")
		if token == "" || token == header {
			envelope.Fail(c, 200, service, action, "100003", "Unauthorized", "")
			c.Abort()
			return
		}
		userID, err := rdb.Get(ctx, "den:token:"+token).Result()
		if err != nil || userID == "" {
			envelope.Fail(c, 200, service, action, "100003", "Unauthorized", "")
			c.Abort()
			return
		}
		c.Set("UserID", userID)
		c.Next(ctx)
	}
}

func UserID(c *app.RequestContext) (string, bool) {
	v, ok := c.Get("UserID")
	if !ok {
		return "", false
	}
	id, ok := v.(string)
	return id, ok && id != ""
}

- [ ] **Step 3: Write minimal implementation**

`Hub` keeps `map[roomID]map[userID][]*websocket.Conn` guarded by `sync.Mutex`. `EmitRoom` writes the success envelope to every connection in the room. `EmitUser` writes only that user. Use `envelope` metadata with a fresh `RequestId`, `Version` `v1`, and the event's service and action. Write with `WriteJSON`. Drop a connection that returns an error.

`Subscribe` upgrades with `websocket.HertzUpgrader{CheckOrigin: func(*app.RequestContext) bool { return true }}`. Read the first message. Parse `Token` and `RoomId`. Invalid token writes `100003` for service `room` and action `Subscribe`, then closes. If the user has no seat in that room, write `200003` and close. Otherwise register the connection and block on `ReadMessage` until it fails, then unregister.

## Self-review

- `CompareHighRoll` winner index is the slice index. `Service` maps that index through the seat list ordered by `seat_no`, and stores `winner_seat`. Draw stores `-1`.
- `StartMatch` returns `Waiting` even if that call filled the queue. `DescribeMatch` returns `Matched`.
- `turn_seat` starts at the lowest occupied seat, which is seat 0 when the creating host is still seated.
- `testbox.Start` truncates all seven tables between tests. Tables have no foreign keys.
